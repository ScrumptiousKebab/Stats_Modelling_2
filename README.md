1. Read through the **Data Brief** document. This provides an overview of the project, the dataset, and the objectives of the analysis.

2. Follow the guidance in the **Suggested Weekly Activities** section of the practical materials for your assigned week.

3. The goal is essentially to complete the weekly lab work, but using the project dataset instead of the example datasets provided in the practicals.

4. Complete your work in an **R script (.R file)** as you normally would during the labs.

5. Upload your completed R file(s) and any relevant outputs to the GitHub repository.

6. Update the **Who Did What** file with a summary of the work you completed so that contributions are clearly documented.
